Drop DIM-format wishlist .txt files in this folder and they will be loaded
automatically by the build engine to score your weapon rolls.

Format (one roll per line):
    dimwishlist:item=<itemHash>&perks=<perkHash>,<perkHash>#notes:<notes>

A great community-maintained starter list is DIM's "voltron.txt":
    https://raw.githubusercontent.com/48klocs/dim-wish-list-sources/master/voltron.txt

Download it into this folder (keep the .txt extension) to enable god-roll
scoring, then restart the backend (or the engine will pick it up on next start).

Lines starting with // are comments. title:/description:/notes: lines are supported.
